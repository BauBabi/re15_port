# RE2 — Liste der SAP-Tonbänke (PC-Fassung), vom Nutzer 2026-10-10

Quelle: Nutzer (Runde 36). Die PC-SAP-Nummern entsprechen den PSX-Bänken in `info/re2leon/`
(z.B. WEAPON09 = ARMS09 Granatwerfer Explosiv — im Port bereits so genutzt, Runde 35 Spur A/B;
ENEMY06 = Hund, ENEMY07 = Kraehen). Raum-Baenke ROOMxxx.SAP = die snd0/snd1-Teile der RE2-RDTs
(ROOM1090 Glasknall = Runde 35 Spur M, aus room1090.RDT geschnitten).
Nutzer-Hinweis: fuer einen TUERKNALL/Einbruch-Ton bei "Door sounds" oder "Zombies breaking through
wood" suchen (ROOM205 / ROOM112 / ROOM106 / ROOM207/209/20A).
