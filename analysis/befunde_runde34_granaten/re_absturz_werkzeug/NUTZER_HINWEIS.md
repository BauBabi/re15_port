# NUTZER-HINWEIS (nachgereicht vom Hauptagenten waehrend deines Laufs)

Nutzer, woertlich: "Bei der Explosion wenn sie einen Zombie erwischt. Und ich kam zur Granate, indem ich
im player Inventory select und so lange r drücke, bis die Granate im Inventar ausgewählt ist. Es gibt in
der Original Version ein weiteres Debug Menu zur Item Auswahl."

-> Absturz = Explosion mit Zombie im Radius (Wurf/Flug laufen).
-> Granate im Original ohne RAM-Patch: Inventar oeffnen, Select, dann R1 wiederholt bis Granate gewaehlt
   (Item-Debug-Menue). vgamepad: BACK = Select, RIGHT_SHOULDER = R1.

Nachtrag Nutzer, woertlich: "Du musst für den Waffen Debug auf einen Player Inventory Item Slot sein mit
dem Cursor...." -> Cursor zuerst auf einen Item-Slot des Spieler-Inventars stellen, DANN Select + R1.
