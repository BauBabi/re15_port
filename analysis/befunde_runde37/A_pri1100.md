## 2. RE-Belege
- ROOM1100.RDT hat KEINE Original-Masken: Kamera-Tabelle @0x24 -> 0x60, 13 Cuts, je pri_offset (Satz +0x1C) zeigt auf
  `FF FF FF FF` (gc/mc = FFFF/FFFF, Cut 0..12 @0x608..0x638), RDT-Kopf Byte[7] = 0 (keine Maskenkapazitaet). Die Masken
  sind Port-Daten (R15M) auf NUTZER-VORGABE (Marken F205/F595: "die Zombies um die Ecke sind durch die Wand sichtbar");
  belegt wird ihre FORM: Original-sprite.pri-Semantik, je Rechteck EINE Tiefe.
- Masken-OT (PSX.EXE FUN_80039590, `re15_disasm.py dis 0x80039640`): `80039650 lh a0,2(s3)` (depth) / `80039658 sll a0,a0,2`
  / `8003965c addu a0,a0,s6` / `80039660 jal 0x8006b538` (AddPrim) -> OT-Wort = depth.
- Figuren-OT je Polygon (@0x8002564c): `80025654 sra v0,v1,6` / `80025658 beq v0,zero,0x80025690` (Nah-Gate) /
  `8002565c sra v1,v1,4` / `80025660 sll v1,v1,2` -> OT-Wort = otz>>4.
- ZSF3 (@0x80066c70): `addiu t0,zero,341` / `80066c74 .word 0x48c8e800` (ctc2 t0,cr29) -> otz = (1023*vz)>>12.
  => Maske verdeckt einen Polygonpunkt gdw. depth < (1023*vz)>>16, d.h. ab vz >= (depth+1)*65536/1023 (re15_pri.h,
  geometrie.py). Ein Rechteck traegt EINE Tiefe: richtig verdecken kann es nur, wenn die Wandtiefe IN ihm schmal ist.
- Bildaufbau: `8001ce54 jal 0x80039590` (Masken) vor `8001d09c jal 0x8001e8c8` (Spieler-Polygone).
